## 1. 主要発見

### A. セクションサイズ別の角番効果の差異

| セクションサイズ | 最強角番 | 平均機械割 | 特徴 |
|:--:|:--:|:--:|:--|
| **small** (≤8台) | 角5 | 100.80% | 中央優位（小島で中央がより強い） |
| **medium** (≤14台) | 角6 | 102.27% | 標準的な中央優位効果（最も安定） |
| **large** (>14台) | 角11 | 101.88% | 外寄り優位の傾向（大島では異なる） |

**解釈**: 島のサイズが大きいほど、中央効果が薄れて外寄り（角11-13）が相対的に強くなる。

## 2. イベント日 vs 通常日での角番選択パターン

### 2-1. セクションサイズ別の pay_rate 差

```
small  : イベント日 100.54% < 通常日 100.97% (-0.44pp)  ⚠️ イベント日が弱い
medium : イベント日 101.83% ≈ 通常日 101.78% (+0.05pp)  ~ ほぼ同等
large  : イベント日 101.61% > 通常日 101.22% (+0.39pp)  ✓ イベント日が強い
```

**重要**: small 島でイベント日が弱い → ホール側がイベント日に small 島の低設定を狙う可能性

### 2-2. Peak rank（最強角番）のイベント日シフト

**2F**:
- small: イベント = 4.08, 通常 = 4.11 (差 -0.02) — ほぼ不変
- medium: イベント = 7.75, 通常 = 7.84 (差 -0.09) — わずかに中央寄り
- **large: イベント = 9.25, 通常 = 7.89 (差 +1.36)** ← **外寄りシフト**

**3F**:
- medium: イベント = 5.58, 通常 = 7.16 (差 -1.57) — 中央寄りシフト
- **large: イベント = 7.67, 通常 = 8.37 (差 -0.70)** ← 中央寄りシフト

**AT**:
- medium: イベント = 6.75, 通常 = 8.32 (差 -1.57) — 中央寄りシフト
- **large: イベント = 9.33, 通常 = 7.26 (差 +2.07)** ← **強い外寄りシフト**

**パターン**:
- **large 島**: イベント日は **外寄り** に設定 → 角9-13 ゾーン優遇
- **medium 島**: イベント日は **中央寄り** に設定（3F/AT）→ 角5-7 ゾーン優遇
- **small 島**: ほぼ変化なし（不規則）

## 3. DD 別の最強角番トレンド

### 3-1. 不規則性の度合い

DD ごとに最強角番が **大きく変動**（各セグメント×セクションサイズで異なる）

**例（2F の場合）:**
```
DD 1 (イベント日): small=5, medium=5, large=13
DD 2 (通常日):    small=2, medium=7, large=11  ← 大きく変わる
DD 3 (通常日):    small=5, medium=6, large=9
...
DD 10 (通常日):   small=5, medium=10, large=13
```

**解釈**: DD による単純な予測は困難 → 複合要因（曜日、イベント日定義、その他要因）の影響が大きい

### 3-2. イベント日マーク（★）での傾向

イベント日（DD=1,4,7,11,14,17,21,22,25,28,30,31）と peak rank の相関は **弱い**

→ イベント日の定義がまだ正確でない可能性、または角番選択以外の要因（全体の設定方針の変更）が優位

## 4. 角番5-11 pay_rate の精密分析

### 4-1. セグメント別の局所ピーク

**2F**:
- 角5-8: 101.5-102.1%（フラット）
- 角9-10: 101.8-102.0%
- **角11: 102.25%** ← 最強

**3F**:
- 角5-11: 101.2-101.6%（完全フラット）
- ピークなし（ノイズレベル）

**AT**:
- 角5-8: 101.2-101.8%
- **角6: 101.82%** ← 最強（わずか）
- **角11: 101.78%** ← 同等に強い

### 4-2. 解釈

- **2F**: 明確な外寄り優位（角11）
- **3F**: ほぼフラット → 角番効果が微弱（他の要因が主）
- **AT**: 中央と外の両方が強い（バイモーダル）

## 5. 既存理論との整合性

### 確認事項

1. **角5-9 が最強という前回仮説**
   - **修正**: より正確には「セクションサイズに依存」
   - small: 角5 ✓
   - medium: 角6 ✓
   - large: 角11（中央ではなく外寄り）✗ ← 新知見

2. **セグメント別の機械割差異**
   - 2F: 102.27% (medium 最大)
   - 3F: 101.2% (全セクション平坦)
   - AT: 101.94% (medium 最大)
   - 確認: セグメント別に効果の大きさが異なる

3. **イベント日での特別な設定投入**
   - **確認**: large 島ではイベント日に外寄り（+1.36～+2.07pp）
   - **矛盾**: small 島ではイベント日が弱い（-0.44pp）
   - **解釈**: イベント日戦略は「大き目の島に高設定を集中」という可能性
