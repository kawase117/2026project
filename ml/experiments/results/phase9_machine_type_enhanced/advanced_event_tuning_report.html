Advanced Event Features (10)

  • event_group: Group A (1,11,21 - 1のつく日), Group B (7,17,27 - 7のつく日), or Month-end (E)
  • event_cycle_phase: (day_of_month % 10) to capture intra-month cycles
  • days_to_next_same_group: Days to next event in same group (グループ内距離)
  • days_to_next_any: Days to next event (any group - グループ間距離)
  • days_since_last_any: Days since last event (any group)
  • is_event_week: 1 if within +/- 3 days of any event
  • event_proximity_score: 1 / (days_to_next_any + 1)
  • next_event_same_group: 1 if next event is in same group
  • event_density_5d: Number of events in last 5 days
