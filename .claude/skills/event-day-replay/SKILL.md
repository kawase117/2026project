# イベント日の過去回リプレイ

2026-10-20、楽園蒲田のハーフテンの予測で確立した手順。**イベントごとに同じ動き**をする。
自動下書き(`scripts/run_morning_docs.py`)は過去回を引かないので、人が必ず回す。

## 0. 予告がどのホールの話か確認する(最初に)

同じ投稿者が複数店舗(楽園蒲田と楽園上永谷など)を書く。予告JSONはホール名が自動で付くので、
**本文の店名を読んで、別店舗なら外す**。同日か別イベントかは本文とユーザー確認で決め、推測で他ホールに当てはめない。
(実例: 10/20、自動下書きが上永谷の予告3件を楽園蒲田の根拠にしていた)

## 1. 同じ系列の過去回を全部引く

- 台帳: `document/registry/EVENT_SERIES.jsonl`(同名・同種の系列)、`EVENT_DAYS.jsonl`、結果は `EVENT_RESULT_LINKS.jsonl`。
- 日付の軸(0の付く日など)で代用しない。**そのホールで初開催なら「前例なし」と明記**し、別ホールの回は参考にとどめる(ホール横断の共通法則は狙わない)。
- 期間内の改装・配置替え・店長交代をまたぐ比較は、前後で分ける。

## 2. 過去回ごとに表を作る

ホール平均差枚/台・総差枚・台勝率・+3000枚以上の台数を、**通常日の平均と並べる**。
次に機種別(5台以上)の上位・下位。ジャグラーは分けて集計する。
見るのは次の点。
- 上位機種が毎回入れ替わるか(前回の勝ち頭が繰り返さない形跡)。
- 特定機種が一貫して上位か、1回の大勝ちで平均が上がっているか(中央値・月別・日別で確認)。

## 3. 公約の構造から軸を決める

| 公約 | 見る軸 |
|---|---|
| ニブイチ・ハーフ(半分に設定) | **台数の偶奇**。奇数台は「繰上」の対象になる。1台機種は偶数になれないので**別掲**し、2台以上で比べる。台数帯で層別し、機種日単位のブートストラップで差の95%区間を出す。**通常日で同じ差がないか**を必ず見る(あればイベント特有ではない) |
| 全台系 | 台数の少ない機種(2〜5台)、前回までの全台系の機種 |
| 並び | 島単位、台番号の連続、前回位置からのずれ |
| 末尾・角番 | セグメント別(ジャグラー/AT)に分けて検証 |

## 4. 高回転×高差枚の台を見る

- 台別に回転数・差枚・BB/RB・RB確率を並べる(`machine_detailed_results`: `games_normalized`, `diff_coins_normalized`, `bb_count`, `rb_count`)。
- **8,000G以上**の台を数える。新台(初出から7日以内)は除外する。通常日との台数・勝率を比べる。
- 8,000G超は設定示唆のあるAT機では打ち手の確信のシグナルとして使える(ユーザーの経験則、データでも勝率約75%)。
  ジャグラーは設定示唆が乏しいので別扱い(RB確率のみ)。
- **回転数は出玉の後に出る指標**で、開店前の予測には使えない(営業中の指標)。回転数が多い台は出た台に偏るので、勝率は上振れる。
  勝率だけで設定を逆算しない。台ごとのRB確率を併記する。

## 5. 現在の状態に照らす

過去回の勝ち頭を、**最新データ**の台数・偶奇・配置と突き合わせる。台数が変わっていれば同列に扱わない。
(実例: ヴァルヴレイヴ2は6台→9台で奇数に、無職転生は4台→1台に)

## 6. 誤読ガード

- 標本が3〜4回なら、そう書く。2回で割れたら「割れた」と書き、強いと言い切らない。
- 単日・単月に偏った平均は、中央値と月別を併記する。
- ユーザーの主張は「主張」として記録し、データの読みと分ける(出所つき)。
- 避ける機種は、前日の結果ではなく同系列の過去回で根拠がある場合に限る。

## 7. 出力

- 予測文書: 「過去回」節として表と読み取りを入れ、「判断:」行に推す機種を書く(`prediction_ledger freeze-doc` が機械抽出する)。
- 結果が出たら、その日を系列の次の1回として追記し、主張の成立/不成立を記録する。
- 手法そのものが更新されたら、このスキルを直す。

## 実行メモ

- Pythonは `venv\Scripts\python.exe -X utf8`。DBは `db/<ホール正式名>.db` を `file:...?mode=ro` で読む(短縮名を渡すと空DBができる)。
- ホール正式名: `楽園蒲田店`、`マルハンメガシティ2000-蒲田1`、`マルハンメガシティ2000-蒲田7`、`みとや大森町店` など。
