# ジャグラー設定予測パイプライン 総括レポート

- 対象: `ml/experiments/jug_rb_setting_prediction/`（Stage1〜6、9ホール展開）
- 連絡ログ: `document/plans/2026-07-06-jug-rb-setting-prediction-codex-log.md`（裁定#1〜#31）
- 作成日: 2026-07-11（裁定#31時点の`multi_hall_summary.csv`を正式版として確定）

## 1. 目的

「朝の情報だけで、その日どのジャグラー台に座るべきか」を、差枚を教師ラベルにせず、
設定別のBB・RB公称確率（1geki.jp・jugglersnet.com由来）から推定した潜在設定確率で
予測できるか検証するプロジェクト。差枚を直接使わないことで、「偶然の大勝ち」を
高設定の証拠と誤認するラベルノイズを避ける設計。

## 2. 方法論の骨格

```
Stage1: 機種カタログ・設定別BB/RB確率マスタの整備
Stage2: 台×日の設定事後分布（尤度=Binomial、事前=経験的π、EMで推定）
Stage3: 特徴量構築（台効果・カレンダー・角番/セクション、リーク検査つき）
Stage4: walk-forward選択（B0乱択/B1台効果/B2線形/M暦+lag/M2+角番LR）+ 実差枚評価
Stage5: 同日同機種内mid-pランク（スペック表非依存の自己校正指標）→ B1R
Stage6: 有望候補の凍結フォワードテスト（みとや専用）
```

対象9ホール: 蒲田7(kamata7)・蒲田1(kamata1)・ARROW(arrow)・レイトギャップ(lategap)・
みとや(mitoya)・楽園蒲田(rakuen)・ヒロキ(hiroki)・ザシティ(zashiti)・金時(kintoki)。
うちヒロキ・ザシティ・金時は分散分解でジャグ台×日シグナル検出限界以下(≈0)と事前確定済みの
「対照群」として扱った。

## 4. ホール別の主な知見

### 4.1 蒲田7（kamata7）: negative result、ただし2つの生存知見

- B1（台効果）/M（カレンダー+lag）/M2（+角番LR）/B1R（機種内mid-pランク）の全手法で
  実差枚のB0超えを確認できず
- **重大な落とし穴の発見（裁定#13）**: 当初のB1はモデル通貨（p_high・e_payout）上で
  +2.5ppのエッジに見えたが、これは「選択ロジックと評価指標が同じ設定事後分布を
  共有する」ことによる**事前分布のこだま**だった。B1の選択は実質100%ゴーゴージャグラー3に
  退化していた。実差枚で検証すると+2.5ppは消滅（+0.1〜0.3pp、CIはゼロを含む）
- **生存知見1**: 両端角（kakuban_rank_min=1、および同=section_size）の機種内相対ランクは
  一貫して0.42〜0.47（中央値0.50に対し明確な低評価）。最も極端な例は22台島の遠端角で0.4215。
  既存の角番instinct（角1は低設定）が独立した測定チャネル（BIG/REGベースのmid-pランク、
  差枚不使用）でも再現された
- **生存知見2**: 台効果の信頼性0.87は主に機種間差（どのジャグラー機種を打つか）に由来し、
  機種内の台差の信頼性は0.49（弱い）。「機種島を選び、角を避ける」までは有効だが、
  それ以上の台粒度の選択には根拠が乏しい

### 4.2 ヒロキ（hiroki）: 有意なnegative、ただしバグではなく理論的に想定される現象

- ヒロキは分散分解でジャグ台×日シグナル検出限界以下(≈0)と事前確定済みの対照ホール
- B1R−B0=−1.04pp[−2.00,−0.13]と有意なnegativeが出たため、裁定#31で個別調査
- 家系echo（蒲田7と同じ機序）ではないことを確認（B1Rはスペック表非依存のため）
- 縮小推定不足のアーティファクトでもないことを確認（mean_G と b_rank_180d の相関r=0.13、
  最頻選択台の平均G数はホール内で高G側ではなく、生スコアでも実際に上位だった）
- **確定判断**: 実力差がほぼゼロのホールで「過去の実績が良い台」を追うランキング戦略は、
  平均への回帰により統計的にランダム選択より劣りうる。これは新しい発見ではなく、
  既存の「シグナル検出限界以下」という結論と整合する現象。**方策としての教訓**:
  ゼロシグナル環境で後ろ向きランキングを運用に投入すると、単に打たない（B0水準）よりも
  悪い結果になりうるため、シグナルの存在を確認する前に運用投入しないことが重要

### 4.3 みとや（mitoya）: 唯一のpositive、ただしフォワードテスト待ち

- B1R−B0=+1.42pp[+0.24,+2.50]で唯一の有意なpositive
- 182日間の選択が実質5台（machine_number: 641, 642, 674, 675, 733）に集中しており、
  縮小推定バイアス（高G台が縮小されにくいだけのアーティファクト）を疑い個別検証した
- 検証結果: 5台の縮小前生スコアはホール内92台中1〜7位相当で、高Gなのに生スコアが低い
  反証台も複数存在。アーティファクトではなく実データに裏付けられた発見と確定（裁定#25）
- **但し書き**: 効果の性質は「日次の広い変動」ではなく、**少数の高トラフィック台・座席への
  持続的な優遇**（2台は機種入替を跨いで座席が選ばれ続けている）。蒲田7の「機種島選び」とは
  質的に異なる、みとや固有の構造
- **多重比較の注意**: 名目p≈0.014だが、9ホール（分析対象は当初6ホール）の多重比較補正
  （Bonferroni×6〜9）後は有意性が消える水準。確定には独立データでの検証が必須
- **フォワードテスト**: `results/mitoya/forward_test_freeze_20260706.json`で候補5台を
  2026-07-06に凍結済み。評価開始2026-07-07、min_eval_days=60が必要。
  2026-07-11現在はまだ5日で「データ不足」判定が正しい状態。**2026年9月頭以降に
  `stage6_forward_eval.py`を再実行し、フォワードテストの成否で最終確定する**

## 5. 方法論的資産（他分析への転用価値）

1. **二項mid-pランク**（同日・同機種内、Stage5）: スペック表・事前分布に依存しない
   自己校正指標。事前分布のこだまを避けたい場面で汎用的に使える
2. **実差枚評価の規律**: モデル通貨（p_high・e_payoutなど自作の換算値）だけで判断せず、
   必ず実差枚（円建て）で答え合わせをする。蒲田7の+2.5pp幻影がこの規律の必要性を実証した
3. **任意停止バイアスの整理（裁定#5）**: ゲーム数Gは打ち手の停止判断に依存する内生変数。
   ただし尤度原理により、停止規則が観測履歴のみに依存する限り、ベイズ推定（事後分布・
   p_high）自体は頑健。壊れるのは単純な検算（観測レートと理論値の比較）の方
4. **事前分布のこだま**: 選択ロジックと評価指標が同じ事前分布・スペック表換算を共有すると、
   自己言及的に「儲かっている」結果が出る。評価は選択ロジックと独立した情報源で行うべき
5. **縮小推定バイアスの検証手法**（みとや裁定#25、ヒロキ裁定#31で反復適用）:
   「生スコア(縮小前)のランキング」と「平均G数」の相関、および高G・低生スコアの反証台の
   有無を確認することで、「データ量が多いから上位に来ただけ」の疑いを直接検証できる

## 6. 既知の限界

- 対象はジャグラー系（Aタイプ）8系統のみ。ハナハナ・沖ドキ系（hana_flag/oki_flag機種）は
  当初の設計対象だったが未実装

  データ拡張後に再評価が必要
- みとやのpositiveは名目有意のみで、多重比較補正後は確定していない。フォワードテスト結果
  （2026年9月頭以降）が最終判断
