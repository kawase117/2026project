# シグナル上限の定量化：機械割の分散分解（全9ホール）

作成: 2026-07-06 / スクリプト: `eda/variance_decomposition.py` / データ: `db/*.db` 全期間

## 目的

「このデータにどれだけ予測可能なシグナルが存在するか」の天井を測る。
個別の仮説検証（DD・曜日・角番…）を積み上げる前に、**そもそも各成分の分散がいくらあるのか**を確定させ、
EDA・MLの継続判断の基準にする。

## モデルと識別戦略

台×日の機械割偏差 `y = diff/(3G)` を二元固定効果で分解：

```
y_it = m + a_t(日効果) + b_i(台効果) + c_it(台×日シグナル=日次設定配分) + e_it(出玉ノイズ)
```

- **a_t, b_i**: 反復demean推定 + split-half信頼性（Spearman-Brown補正）でノイズ除去後の「真の」分散を推定
- **c_it vs e_it（diff法）**: `E[r²] = Var(c) + v/(9G)` の 1/G 回帰（機種名別→加重集計）
- **c_it（RB法・ジャグラー限定）**: `z = RB回数/G` は設定でほぼ決まり、G所与で二項分布。
  `Var(c_z) = Var(残差) − mean(p(1−p)/G)` と**解析的に**ノイズを差し引ける
- **日効果のカレンダー予測可能性**: 曜日+日末尾+ゾロ目+強ゾロ目+月初末+祝日で5-fold CVのOOS R²

### 重要な方法論的発見：diff法は約3倍過大

出玉が良い台ほど長く回される（打ち切り・続行の内生性）ため、G数は結果変数であり
1/G回帰の識別仮定が壊れる。ジャグラーで diff法 5.5〜7.5pp に対し RB法 0〜2.9pp。
**差枚ベースの台×日シグナル推定は今後すべて「上限値」としてのみ解釈すること。**
AT機の 12〜21pp という数字も同様に上限であり、真値はその数分の一の可能性が高い。

## 5つの結論

### 1. 最大の変数は「どのホールか」— 幅5.7pp
平均機械割はヒロキ94.0%〜蒲田7 99.75%。**ホール選択1つで、台×日予測が理論上稼げる幅（±2〜3pp）の2倍が動く。**
蒲田7・蒲田1にいること自体が最大のエッジ。

### 2. 単日の出玉はSN比 1:5〜1:12 のノイズ
出玉ノイズSDは9.5〜23.3pp。全シグナル成分（1〜3pp）の5〜12倍。
「昨日の差枚」から設定を逆推定する行為の情報量は構造的に僅少。
複数日の集約（台効果推定）でのみノイズは削れる。

### 3. 3ホールはジャグラー設定を日次でほぼ動かしていない
RB法でベルシティ・ヒロキ・金時の台×日シグナルは検出限界以下（≈0pp）。
**この3ホールでの日次設定予測（ジャグ）は、当てる対象が存在しない。**
金時は日効果信頼性0.12で日単位の強弱すらほぼ幻。
一方、蒲田7（2.86pp）・蒲田1（2.60pp）は明確に存在し、ML対象として正当。

### 4. 最も信頼できる予測資源は「台効果」（恒常的な台差）
split-half信頼性0.82〜0.96。日次予測より台ランキングの方が統計的に一桁堅い。
レイトギャップの台効果SD 5.01ppは機種構成差を含むが、それ自体が着席判断に使える情報。

### 5. カレンダー（DD・曜日・ゾロ目・月末）で説明できる日効果はわずか
OOS R²: ヒロキ27%・レイトギャップ21%が例外で、**他は≦9.2%（蒲田7ですら9.2%）**。
これまでのDD軸・曜日軸EDAで「nullばかり出た」のは探し方の問題ではなく、
**説明されるべき分散がもともと小さい**ことの帰結。カレンダー深堀りの追加投資は蒲田7・ヒロキ・レイトギャップ以外では回収不能。

## 意思決定への含意

- **続ける価値**: 蒲田7/蒲田1の台×日予測（σ≈2.6-2.9pp）、全ホールの台効果ランキング、ヒロキ/レイトギャップのイベント日タイミング
- **やめるべき**: 金時・ベルシティのジャグ日次予測、蒲田1などカレンダーR²≈0のホールでのDD/曜日深堀り、差枚ベースの単日設定推定
- **現実的エッジの算術**（蒲田7ジャグ例）: base 99.75% + 台選択+1〜2pp + 日選択+1〜2pp + 台×日予測（相関0.3と仮定で+0.9pp×選択効果）→ **合計+3〜5ppが上限帯**。「常時104%超」はジャグでは構造的に薄く、Top-N選択と日選びの複利で狙う設計が正しい
- **次フェーズ（円建てバックテスト）**: 「台効果＋日効果のみの単純戦略」を必須ベースラインにすること。MLがこれに勝てなければσ_cは取れていない

## 限界

- **任意停止バイアス（2026-07-06追記）**: G数は遊技者が途中経過を見て決める停止時刻であり、
  固定標本サイズではない。RB法のノイズ差し引き `Var(r) − mean(p(1−p)/G)` はモーメントベース
  のため任意停止の影響を受け、停止による余剰分散の分だけ **Var(c) はやや過大（上限寄り）**。
  K7=2.86pp等の値は上限として解釈すること。3ホール≈0の結論は影響を受けない（0未満にはならない）。
  なお尤度ベースの推論（設定事後分布）は尤度原理により任意停止に頑健（ジャグRB設定予測の裁定#5参照）。
- RB→機械割換算は近似係数75に依存（±20%の不確実性）
- AT機のVar(c)は上限しか測れていない（打ち切り内生性）。AT機の真の日次シグナル量は未解決の最大の不確実性
- c_it は日次独立を仮定していない（据え置き相関はc内に含まれる）
- ハナハナはサンプル僅少のホールが多く未確定
