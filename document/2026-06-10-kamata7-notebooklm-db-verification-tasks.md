# 蒲田7 NotebookLM要約 DB検証タスク

**作成日:** 2026-06-10  
**対象ホール:** マルハンメガシティ2000-蒲田7  
**元レビュー文書:** `document/2026-06-10-kamata7-notebooklm-slide-review.md`  
**目的:** NotebookLM 要約から採用候補として残した仮説を、蒲田7単体の DB で検証可能なタスクに分解する

---

## 1. 方針

- 他店比較は使わない。
- NotebookLM の断定表現は使わない。
- 全タスクで、**平均差枚だけでなく勝率・104%以上率・サンプル数**を併記する。
- 目立つ単日結果ではなく、前後比較または期間比較で判断する。
- 万枚台数は補助指標にとどめ、主指標にしない。

---

## 2. 共通前提

### 2.1 主に使うテーブル

- `machine_detailed_results`
- `daily_machine_type_summary`
- `machine_master`

### 2.2 基本指標

- `avg_diff_coins` または台平均差枚
- `win_rate`
- `hit104_rate`
  - 実装済み定義があればそれを優先
  - 未整備なら暫定的に `機械割104%以上` 相当の既存集計に合わせる
- `sample_count`
- 必要に応じて `median_diff`

### 2.3 集計ルール

- 可能なら `games_normalized >= 1000` などの最低稼働フィルタ有無を併記する
- フィルタあり/なしで結論が変わるか確認する
- 機種名は raw 名称ではなく、既存の正規化ルールに従う

---

## 3. タスク一覧

## Task 1. 2026-05-30 前後の営業レジーム変化検証

### 目的

NotebookLM 要約で示唆された「5月末にジャグラーや主力AT機の配分方針が変わった可能性」を、単日イベントではなく前後比較で検証する。

### 見たい問い

1. `2026-05-30` を境に、ジャグラー系の成績は有意に変わったか
2. 同じ境界で、主力AT機も同方向に変わったか
3. 変化が単日スパイクなのか、数日以上継続するのか

### 集計単位

- 日次 × 機種カテゴリ
- 比較期間の候補:
  - `2026-05-01` から `2026-05-29`
  - `2026-05-30` から `2026-06-07` もしくは最新日

### 最低限の分割

- ジャグラー系
- 主力AT機
  - 候補: 東京喰種、北斗、モンキー、ToLOVEる
- その他

### 主要指標

- 台平均差枚
- 勝率
- 104%以上率
- 台数
- 日数

### 出力

- 前後比較表
- 日次推移表
- 「単日だけ強い / 継続して強い」の短い判定コメント

### 判定基準

- `2026-05-30` 当日だけでなく、その後の数日にも同方向の改善があるか
- ジャグラーだけでなく、他カテゴリとの相対差が拡大したか

---

## Task 2. 新台導入直後は弱い仮説の検証

### 目的

NotebookLM 要約の「新台4機種が弱かった」を、特定4機種の話ではなく、蒲田7全体の導入直後パターンとして成立するか確認する。

### 見たい問い

1. 新台導入 `1-3日` は弱いか
2. 導入 `1週間` は弱いか
3. 導入 `2週間` まで弱さが残るか
4. その弱さは人気AT機だけの現象か、広く見られるか

### 必要前処理

- `debut_date` を機種ごとの最古日で定義
- `days_since_debut` を付与
- `pre_existing` 機種は別扱いまたは除外

### 推奨バケット

- `0-2日`
- `3-6日`
- `7-13日`
- `14-29日`
- `30日以上`

### 主要指標

- 台平均差枚
- 勝率
- 104%以上率
- サンプル台数
- 対象機種数

### 出力

- `days_since_debut` バケット別比較表
- 新台カテゴリ別の簡易ランキング
- 「導入直後回避」がルール化できるかの短評

### 判定基準

- `0-2日` と `3-6日` が `30日以上` より明確に弱いか
- 稼働量差だけでは説明しにくいか

## Task 3. 高分散機種の見かけ上の強さ検証

### 目的

「万枚達成が多い機種は強く見えるが、平均期待値は弱いことがある」という仮説を、蒲田7の高分散機種で確認する。

### 見たい問い

1. 万枚頻度が高い機種ほど平均差枚も高いのか
2. 勝率・中央値で見ると評価が逆転する機種があるか
3. 爆発報告に引っ張られやすい代表機種はどれか

### 候補機種

- ミリオンゴッド系
- 東京喰種
- その他、月間で大きな上振れが多いAT機

### 主要指標

- 万枚到達率
- 台平均差枚
- 差枚中央値
- 勝率
- 104%以上率
- 下位側の損失の大きさ
  - 例: 下位25%平均差枚、負け日の平均差枚

### 出力

- 機種別比較表
- `万枚頻度順` と `平均差枚順` の順位差
- 「目立つが期待値は弱い」機種の抽出

### 判定基準

- 万枚頻度は高いが、平均差枚や勝率が弱い機種が実在するか
- その機種を `避けるべき高分散機種` と呼べるだけの一貫性があるか

## Task 4. 5月好調機種の再現性チェック

### 目的

NotebookLM 要約に出てきた「5月に好調だった機種群」が、一時的な月次ノイズか、短期 prior として使える程度の継続性を持つか確認する。

### 対象候補

- L東京喰種
- Lスマスロ北斗の拳
- スマスロモンキーターンV
- L ToLOVEるダークネス
- ジャグラー系上位機種

### 見たい問い

1. 5月中の好調は月前半/後半どちらに寄っていたか
2. 6月初旬まで継続したか
3. 人気と高稼働だけで説明できるか

### 主要指標

- 半月単位の台平均差枚
- 半月単位の勝率
- 日次のブレ幅
- 稼働量との相関の概観

### 出力

- 5月前半 / 5月後半 / 6月初旬 比較表
- 「短期 prior 候補」「単月ノイズ寄り」のラベル付け

### 判定基準

- 5月後半だけ急騰しているならレジーム仮説寄り
- 5月全体で安定して高いなら短期 prior 候補
- 稼働依存が強すぎるなら採用見送り

## 4. 優先順位

実行順の推奨は以下。

1. **Task 2: 新台導入直後は弱い仮説**
2. **Task 1: 2026-05-30 前後の営業レジーム変化**
3. **Task 3: 高分散機種の見かけ上の強さ**
4. **Task 4: 5月好調機種の再現性**

理由:

- Task 2 はルール化しやすく、実務価値が高い
- Task 1 は営業方針変化の確認として重要
- Task 3 は評価軸の補正に効く
- Task 4 は prior として使えるかの最終確認
