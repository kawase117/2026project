# Codex プロンプト: 蒲田7 DD条件付きセグメントヒートマップ

## 目的

蒲田7の台番号×位置データから、DD（日付の日）別に10台ブロックの104%超え率ヒートマップを作成し、
全期間平均では見えないDD条件付きのセグメント構造（特にLR効果）を検出する。

## 背景

- 蒲田7の全期間平均でEven/Odd（LRプロキシ）を比較すると104%率は**両方43.8%で差がゼロ**
- しかし過去の分析でsection_size（LRに相当）がF値で1000倍有効と実証済み
- この矛盾は「LR効果が特定のDD日にのみ発動する」ことを示唆
- DD別にヒートマップを再作成すれば、条件付きセグメントが浮かぶはず

## 実装要件

### データソース
- DB: `db/マルハンメガシティ2000-蒲田7.db`
- テーブル: `machine_detailed_results`
- フィルタ: `games_normalized >= 1500`
- 日付からDD（日）を抽出: `CAST(SUBSTR(date, 9, 2) AS INTEGER)`

### 出力スクリプト
- ファイル: `eda/kamata7_dd_heatmap.py`
- DB path: デフォルト `db/マルハンメガシティ2000-蒲田7.db`、引数で変更可能

### 処理内容

1. **全期間ベースライン**（既に完了、検証用）
   - 10台ブロック（台番号の十の位）ごとに104%超え率を計算
   - フロア別（2F: 2000-2999, 3F: 3000-3999）に分離

2. **DD別ヒートマップ**（メイン）
   - DD=1〜31の各日について、10台ブロック×104%超え率を計算
   - サンプルサイズが5未満のセルはNaN扱い
   - 出力: CSV形式（行=10台ブロック、列=DD1-31、値=104%超え率）

3. **DD別Even/Odd比較**
   - DD=1〜31の各日について、Even台とOdd台の104%超え率を計算
   - Even-Odd差分を計算し、差が大きいDDを検出
   - 出力: CSV（行=DD、列=Even率/Odd率/差分/サンプル数）

4. **DD別位置クォータイル**
   - フロア×DD×Q1-Q4の104%超え率
   - 出力: CSV（行=フロア_クォータイル、列=DD1-31）

### 出力先
- `eda/results/kamata7_dd_heatmap_by_section.csv`
- `eda/results/kamata7_dd_even_odd.csv`
- `eda/results/kamata7_dd_quartile.csv`
- コンソールに要約統計量（Even/Odd差が5pp以上のDD一覧、クォータイル差が大きいDD一覧）

### 注意事項
- `to_markdown()` は使わない（環境によってエラーになる）
- 空セグメントのNaN処理を忘れない
- printでの日本語出力はUTF-8エンコーディングを明示
- 台番号2026は鉄台なので除外する

## 期待される発見

- 特定のDD（例: DD7, DD11等のイベント日候補）でのみEven/Oddに差が出るパターン
- DDによってクォータイル構造（W字/U字）が変化するパターン
- 冷却/加熱ゾーンがDD条件で入れ替わるパターン

# Claude プロンプト: DD条件付きセグメント分析の解釈

## 目的

Codexが生成したCSV結果を読み込み、DD条件付きセグメント構造を解釈する。

## コンテキスト

以下の3つのCSVファイルが生成済み:
- `eda/results/kamata7_dd_heatmap_by_section.csv` — 10台ブロック×DD別104%率
- `eda/results/kamata7_dd_even_odd.csv` — DD別Even/Odd比較
- `eda/results/kamata7_dd_quartile.csv` — フロア×DD×クォータイル

### 全期間ベースライン（既知）
- 2F: 351台, avg=+311, 104%=42.7%（比較的均一）
- 3F: 364台, avg=+199, 104%=44.9%（W字構造: Q1=39.9%, Q2=45.8%, Q3=45.0%, Q4=48.9%）
- Even/Odd: 全期間で差なし（両方43.8%）
- 冷却ゾーン: 3060-3090 (36.6-37.6%), 2200x (37.1%)
- 加熱ゾーン: 3330x (52.7%), 2150x (50.2%)

### 分析すべき問い

1. **LR効果のDD条件性**: どのDDでEven/Odd差が5pp以上出るか？
   - そのDDは既知のイベント日（7のつく日、1のつく日、ゾロ目、月末）と一致するか？

2. **冷却/加熱ゾーンのDD依存性**: 3060-3090の冷却ゾーンは全DD共通か、特定DD日にだけ冷却するか？

3. **3FのW字構造のDD依存性**: Q1-Q4の構造はDD別に変化するか？
   - 特定DDでW字→U字に変わる、Q1が急上昇するなどのパターンはあるか？

4. **セグメント定義への示唆**: DD条件付きで見えた構造から、蒲田7のセグメント定義（2F_A/2F_N/3F_L/3F_N等）を再発見できるか？

### 出力形式

- 発見事項を箇条書きで整理
- 他ホール検証手順への組み込み方を提案
- instinct exportすべき知見があれば指摘
