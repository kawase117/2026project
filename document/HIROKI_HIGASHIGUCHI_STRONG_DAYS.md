## 強い日の定義

## 申告との照合

- **「普段は弱い」**: 全日平均−41、中央値−55。整合する。
- **「スロパチは強い」**: 10/11(+726)は整合。9/26「スロパチステーション来店取材(オレンジ)+6のつく日」は+202で強い日の基準には届かないが、全日平均(−41)よりは高い。**スロパチの日は台帳上2日だけで、統計的な判断はできない。**
- **「月1回の強い日がある」**: 量は整合。ただし**「月に必ず1回」は成立しない**(下記)。

## 月ごとの回数(「月予算」説の検証)

1か月ぶんそろう21か月のうち、強い日が **0回の月が7か月**(2025-01、03、10、11、12、2026-04、05)、1回が9か月、2回以上が5か月(最大は2025-08の4回)。強い日の間隔は4〜119日で、規則的ではない。

「その月にまだ強い日が出ていないとき、残りの日数が減るほど出やすくなるか」(予算を使い切る方向):

| 月のなかの日付帯 | 強い日が出た日数 / 未出の月の日数 | 発生率 |
|---|---:|---:|
| 1〜7日 | 3 / 148 | 2.0% |
| 8〜14日 | 8 / 109 | 7.3% |
| 15〜21日 | 1 / 71 | 1.4% |
| 22〜31日 | 3 / 76 | 3.9% |

17日までに強い日がなかった10か月のうち、18日以降に出たのは3か月だけ。**月末に近づくほど出やすくなる傾向は見えない。** ご指摘の「18日時点で残り14日なら1/14(約7%)」は、仮説どおりなら成立する数字だが、実データの15〜21日の発生率は1.4%で、それより低い。また、10月は10/11(+726)がすでに強い日で、仮説の前提(今月はまだ強い日がない)を満たさない。**仮説が正しければ、10/18の出現確率はむしろ低かった**ことになり、10/18は「月予算」説とは合わない。

## 10/18は、事前に予見できたか

開店前に分かった条件と、過去の強い日の発生率(全日基準 3.5%):

| 条件 | 強い日 / 該当日 | 率 |
|---|---:|---:|
| 日曜 | 13 / 93 | 14.0% |
| 日曜で前日がマイナス | 9 / 56 | 16.1% |
| 2026年の日曜で前日がマイナス | 4 / 24 | 16.7% |
| 10/18の条件(日曜、18日、前日10/17は−102、取材) | | 約16% |

- **開店前の予見は、「日曜の約6回に1回」(約16%)が限度だった。** 全日基準(3.5%)の約4.6倍で、注意を向ける根拠にはなるが、「強い日」と予見できるほどではない。
- **取材だけでは、強い日の予見にならない。** 台帳の14の取材日の平均は+82(同期間の全日平均は−26)と高めだが、強い日は10/18の1日だけ(7%)。HALF BURSTは3回(−17、−112、−102)、5/16の「最強6の日(割/切リサーチ)」は−112で、すべて強い日ではなかった。
- **前日が強い日だと、翌日は強い日にならない**(0/22)。10/11(+726)の7日後に10/18が来たが、これは一般則とは別。
- **公約の大きさ(店内15%=42台以上、計5箇所)は、予見の材料になりうるが検証できていない。** 過去の公約の数値を、強い日と照らして調べる材料(予告の構造化)が足りない。
- **営業中の観測では、昼に検出できた。** 13:31のスキャンで、マイジャグラーVの列(2053〜2067、12台)の合算が23,184GでRB113(1/205)、設定平均なら偶然に起きる確率は約0.003%。開店後の数時間で、「今日は強い日」と判断できた。

## 結論と次の手

1. 強い日は「月1回程度」という頻度の申告と整合するが、**月ごとの規則(月予算)は、データで支持されない。**
2. 10/18を開店前に「強い日」と予見するのは、約16%(日曜の6回に1回)が限度。**予見よりも、営業中の早期検出に価値がある。**
3. 営業中の検出は、列・島ごとの合算RB(実装を予約済み)と、台帳の「強い日の兆候」(列全体の偏り)を組み合わせる。
4. 未検証: スロパチの日(2日だけ)、予告の公約の大きさ、強い日の前後の動き(強い日の直後に弱くなるか)。

## 参考: 検証に使った計算の限界

- 強い日の閾値(+300)は、頻度の申告に合わせた置き方で、他の置き方(+200、+400)でも結論の向きは変わらないかは確認していない。
- 台帳の13日は2025年のもので、当時のホール状況(台数260台、レイアウト)が現在と異なる。
- イベント台帳は2026-04以降が中心で、2025年の強い日のイベントの有無は確認できていない。
