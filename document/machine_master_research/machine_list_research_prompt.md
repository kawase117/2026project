# 機種スペック調査プロンプト（Gemini用）

## 依頼内容

添付の `machine_list_for_research.csv` には、パチスロホール分析対象の機種名が300件含まれています。
各機種について、以下の情報を調べてCSVの該当列を埋めてください。

## 埋めてほしい列

| 列名 | 内容 |
|------|------|
| manufacturer | メーカー名（例：サミー、北電子、山佐など） |
| release_date | 導入日（YYYY-MM形式、わかればYYYY-MM-DD） |
| machine_type | 機種タイプ（AT, ART, ノーマル, A-ART, スマスロ, etc） |
| rtp_setting1〜6 | 機械割（出玉率, %）設定1〜6 |
| bb_setting1〜6 | BB（ビッグボーナス）確率 設定1〜6（分母表記、例：1/270） |
| rb_setting1〜6 | RB（レギュラーボーナス）確率 設定1〜6（分母表記、例：1/400） |
| notes | 備考（ART確率、データ不足時の注記など） |

## 注意事項

- スマスロ機種はBB/RBの代わりに「天井ゲーム数」「AT初当たり確率」などを `notes` 列に記載してください（カラムは空欄でOK）。
- データが見つからない機種は空欄のままでよい。`notes` に「情報なし」と記載。
- 表記ゆれにより同一機種が複数行になっている可能性は排除済み（300件は重複なし）。
- 一部「/いざ番長/SB8」「/ギルティクラウン2/XF」のような不自然な名前が含まれている。これはスクレイピング時の表記異常の可能性が高いため、推測できる場合は正式機種名を notes に記載してください（例: 「Lいざ番長 第3章」の可能性、要確認）。

## 出力形式

埋めたCSVをそのまま返してください（同じ列構成、UTF-8、ヘッダー行維持）。
