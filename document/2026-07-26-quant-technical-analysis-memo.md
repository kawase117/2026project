# テクニカル分析とクオンツの寄与度分解 — 理解メモ

元記事: [クオンツはテクニカル分析を寄与度分解の中で見ている](https://zenn.dev/gamella/articles/7e1af53f19d94d)（北山氏, 2026-07-25）

## 1. きっかけになった実験

- @syakkin3氏が東証20年分のデータをAI（fable5, codex）に読ませ、「窓埋め」「三尊」などテクニカル分析の定番パターンに統計的優位性があるか総当たり検証
- 結果：優位性はほぼ存在せず。唯一残った「空売り側の優位性」も、実際には空売りできない銘柄がデータに混入していたバグが原因で、現実には取れない偽物の儲けだった
- 同様の結論は2006年の書籍『テクニカル分析の迷信』（David Aronson）でも、6,000超のルールを統計的に検証済み。データマイニングバイアス（大量に試せば偶然当たるルールが必ず出る問題）を補正すると、伝統的ルールの大半に有意性なし

## 2. でも「テクニカル分析は無意味」ではない、という整理

クオンツは株のリターンを「共通要因」＋「銘柄固有の理由（specific）」に分解して見る「リスクモデル」（代表例：Barraモデル）を使う。

```
銘柄のリターン = 市場要因 + 業種要因 + バリュー要因 + サイズ要因 + モメンタム要因 + リバーサル要因 + … + 銘柄固有の理由（specific）
```

- **モメンタム要因**＝トレンドフォロー（流れに乗る）に対応。多数銘柄・長期データで繰り返し観測される、統計的に確認された規則性
- **リバーサル要因**＝逆張り（急落した銘柄は戻りやすい）に対応。日本株モデルで特に重視
- 三尊・窓埋めのような複雑なチャートパターンは、この共通要因リストに載るだけの安定した統計的根拠が確認されておらず、「成分」として認識されていない（効果がマイナスと判明したのではなく、そもそも候補にすら入っていない）

## 3. 認められた2要因も「取りすぎ注意」の対象

- モメンタム・リバーサルは、儲けの源泉というよりリスク管理の対象として分類される
- 理由：効果が出る時期と逆効果になる時期が入れ替わる（ファクターローテーション）が、反転のタイミングを事前に読むのが極めて困難
- 実例：モメンタムファクターは2026年前半3ヶ月で+30%超の歴史的強さ→7月に入り、ゴールドマン・サックスのTMTモメンタムバスケットが17営業日で約-40%のドローダウン

## 4. 実務対応：ニュートラライズではなく「除外」

- 「ファクターへのエクスポージャーをゼロに寄せる（打ち消す）」処理（ニュートラライズ）は線形回帰ベースのため、分布の真ん中にはよく効くが外れ値領域では効きが弱い
- 直近急騰・急落した銘柄はまさにこの外れ値領域。学習データも薄く、機械学習モデルは意図せずリバーサル成分を強めた挙動をしがち
- 実務的解決：モデルを賢くする方向ではなく、**ユニバースから直接除外する**
  - 例：直近20営業日のボラティリティ上位5〜10%を除外
  - 例：直近5〜10営業日のリターンが外れ値的に沈んでいる銘柄を除外
- 効果：リターンの絶対値は減るが、ドローダウンが大きく抑えられ、シャープレシオ（リスク調整後リターン）は改善することが多い

## 5. 寄与度分解の実例（yoshiso氏のモデル）

- 寄与度分解＝ポートフォリオのリターンを「今月のリターンのうち何%がモメンタム由来、何%がリバーサル由来、何%が銘柄選択そのものの成果か」に数値で示すもの。ファンドマネージャーの成績表のようなもの
- yoshiso氏のモデルは、リターンのほぼ全てが「specific（銘柄固有の理由）」で説明され、共通要因（モメンタム・リバーサル等）への依存が極めて小さい
- **重要な理解ポイント**：「specific部分の金額が大きい」のではなく、「**リターンの構成比がほぼ100%specific**」という点が評価されている
  - なぜ良いとされるか：①共通要因に頼っていない＝流行りに乗っただけでなく本物のスキルの証明になる／②共通要因は反転リスクが高いため、依存度が低いほどドローダウンの巻き添えを受けにくい
- 著者の「猟奇的」「鋼鉄の意思」という表現は、「絶対に共通要因のせいで損をしたくない」という姿勢を極端なまでに徹底している珍しいモデルだ、という驚き半分・賞賛半分のニュアンス

## 6. さいごに（記事の結論部分）

- 一部読者から「統計で優位性が見つからないなら結局パッシブでいいのでは」という反応があった。著者はこれを「十分に合理的な帰結」と認めつつ、それでもアクティブに踏みとどまるなら、本題は「外れ値を除外したその先、プロが何を根拠に銘柄を選んでいるか」だと締めている

## 用語解説（後で忘れても読めるように）

- **パッシブ運用**：日経平均やS&P500など株価指数（インデックス）にそのまま連動するよう機械的に幅広い銘柄を保有する運用。個別銘柄の選別・予測をしない。手数料が安く、長期的には多くのプロの成績を上回ることが統計的に知られる
- **アクティブ運用**：自分の分析・判断で市場平均を上回ることを狙う運用。クオンツ（統計・数式でモデルを組んで運用する人たち）や記事著者はこちらの実践者
- **クオンツ**：統計的・数学的モデルを用いて投資判断を行う運用者
- **寄与度分解（Attribution）**：リターンを要因ごとの内訳に分解して見る手法
- **リスクモデル（Barraモデル）**：銘柄リターンを市場・業種・スタイル（バリュー・サイズ・モメンタム・リバーサル等）の共通要因＋銘柄固有の残差に分解する統計モデル
- **モメンタム**：直近上がっている銘柄はさらに上がりやすいという傾向（トレンドフォロー）
- **リバーサル**：直近急落した銘柄は戻りやすいという傾向（逆張り）
- **ファクターローテーション**：ある要因（モメンタム等）が効く時期と逆効果になる時期が入れ替わる現象。反転タイミングの予測は困難
- **ニュートラライズ**：特定要因へのエクスポージャー（賭け度合い）をゼロに近づける調整処理。線形回帰ベースのため外れ値領域では効きが弱いという弱点がある
- **specific（固有）リターン**：市場・業種・スタイル等の共通要因では説明できない、銘柄固有の理由によるリターン部分
- **データマイニングバイアス**：大量にパターンを試せば、偶然良く見えるルールが必ず出てきてしまう統計的な罠

## 私（Claude）が補足した見解

### コメント「ボラのデカい銘柄は機関投資家以外お断り、だからパッシブ論になる」への評価

このコメントは記事の論理をやや粗く単純化しすぎだと考える。

- 記事が高ボラ銘柄を避けるべきとする理由は「資金力でトレンドを動かせるかどうか」ではなく、**統計モデルが外れ値領域でうまく機能しないというモデリング上の限界**（データが薄い、ニュートラライズが効きにくい）
- 機関投資家は逆に「注文が大きすぎて自分の売買が値段を動かしてしまう」市場インパクトコストという別の悩みを抱えており、「大きい投資家だから高ボラ銘柄も安全」という前提自体が単純化しすぎ
- 記事中の「パッシブでいいのでは」は著者が読者の一意見として紹介したものであり、記事全体の結論ではない。著者自身の提案は「外れ値銘柄をユニバースから除外する」というシンプルだが能動的（アクティブ）なリスク管理ルールであり、パッシブ化とは別方向

### この考え方の自身のパチンコ（スロット）分析プロジェクトへの応用可否

寄与度分解という「監査の発想」自体は応用できるが、「specific比率が高いほど良い」という**結論は逆転する**、というのが独立した見解。

- パチンコPJでは「共通要因」＝DD・角番・イベント日・曜日・ホールfixed effectであり、これらは既に**再現性が確認された信頼できるエッジの源泉**（ホール側の構造的な投資戦略に基づくため、株の「ファクターローテーション」のような不安定な反転リスクが低い）
- 一方「台固有のspecific残差」に賭ける台選択は、複数の検証で**実質エッジなし（≈0）**と既に結論づけられている（設定は台の個性ではなく、ホールが日次で割り振るものであるため）
- したがって、このPJでの正しい基準は株とは逆で「**既知の構造的要因で説明できる比率が高いほど信頼できる。台固有residualへの依存が大きいバックテスト結果はデータマイニングバイアス（三尊・窓埋めと同種の罠）を疑うべき**」
- 具体的な応用案：バックテスト結果の利益を「DD要因／角番要因／イベント日要因／ホールfixed effectで説明できる部分」と「説明できない台固有residual」に分解する診断スクリプトを作成し、モデルの頑健性を可視化する
