## 2. 機種横断一致度スキャン（ホール一致度＋機種単体検定、2026-07-02）

**結論**: `eda/machine_dd_cross_agreement_scan.py`/`machine_weekday_cross_agreement_scan.py`（「その日、何機種が自分自身の平均を上回ったか」をホール横断で二項検定）を実行した結果、ヒロキはDD軸・曜日軸ともに**有意な日がゼロ**だった。機種数不足ではない（DD区分あたり平均101機種、`insufficient`扱い0件）ため、ヒロキは機種横断で揃って動く投入日パターン自体を持たない、または今回の残差ベース設計では検出できない別方式（機種を絞った個別投入等）を使っている可能性がある。9ホール中、DD軸で有意ゼロだったのは楽園・ヒロキ・ザシティの3ホール、曜日軸も含めて完全にゼロだったのはヒロキ・ザシティ・蒲田1・レイトギャップ・ARROW・金時。

## 5. 新ハナビ 曜日別/DD別 高設定率パターン（2026-07-21）

**前提**: 新ハナビは技術介入機で通常は設定1が大半。「RB確率が設定5理論値(1/306.2)以上」は本来レア。それでも下記の曜日・DDで突出して出現しており、店側の意図的な設定投入シグナルと見て良い水準。

**方針**: χ²検定は非有意だが（DD単位n=10〜13/日、曜日単位n=45〜57）、サンプル不足による非有意を「効果なし」と即断しない。スロットはギャンブルであり店側のトレンドを含むため、有意性検定に固執しすぎるとデータ蓄積を待つ間に店の戦略変化を見落とすリスクがある。

### 曜日別

| 曜日 | 出現率 | 評価 |
|------|--------|------|
| 土曜 | 36.8% | 最優先 |
| 日曜 | 30.9% | 準候補 |
| 水曜 | 28.3% | 準候補（業界一般の「設定投入日」説と符合） |
| 金曜 | 21.2% | 中の下 |
| 月・火・木 | 約17% | 据え置き警戒、平日前半は避ける |

### DD(日にち)別

| DD | 出現率 | 評価 |
|----|--------|------|
| 30日 | 54.5% | 最強シグナル |
| 26日 | 53.8% | 最強シグナル |
| 25日 | 50.0% | 最強シグナル |
| 28日 | 45.5% | 最強シグナル |
| 7日 | 41.7% | 単独ピーク（給料日/イベント日の可能性） |
| 6・11・16日 | 38.5% | 5の倍数±1、給料日周辺の広がり |
| 9・10日 | 0.0% | 明確に回避 |
| 1・22・29日 | 8.3% | 明確に回避 |

χ²検定: DD軸 p=0.242、5の倍数日 p=0.63 → いずれも有意水準に届かないが、n数不足（DD単位10〜13件）が原因であり効果なしの証拠ではない。

### 複合ルール（優先度順）

1. 土曜×25〜30日が重なる日 — 最優先出撃日
2. 土曜単体 または 月末単体(25〜30日) — 積極候補
3. 日曜・水曜・7日 — 準候補
4. 月・火・木、かつ1・9・10・22・29日 — 見送り優先

### 付帯知見

- 台番(2302/2303)自体には偏りなし(28.4% vs 30.9%、独立) → 「どちらの台か」より「いつ行くか」が支配的要因
- ゾロ目日(MM=DD、例5/5・6/6)は15.4%(2/13)でむしろ低め（サンプル不足で検定不可）

### 運用上の注意

- サンプルはDD単位10〜13件、曜日単位45〜57件とまだ発展途上。「確定パターン」ではなく「賭ける価値のある仮説」として扱う
- データ蓄積を継続し、DD単位30件超の段階で再検証する
