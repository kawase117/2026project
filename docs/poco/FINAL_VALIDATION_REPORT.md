# 最終検証レポート：モグ玄・ぽこ データ信頼性評価

**作成日**: 2026-06-02  
**検証対象**: モグ玄（Mogendo）データ、ぽこデータ抽出  
**結論**: **モグ玄は信頼度低。ぽこは信頼度高。**

---

## エクゼクティブサマリー

| 評価項目 | モグ玄 | ぽこ | 判定 |
|---------|--------|------|------|
| **日付精度** | ⚠️ 50% shift | ✅ 100% match | ぽこ > モグ玄 |

---

## 詳細分析結果

### 1. 日付ズレ分析（修正後）

#### Mogendo Summary vs Detail

**問題**: 日付が一致しない

```
0day（同日）:  12件 (50%)
+1day（翌日）:  10件 (42%)
-1day（前日）:   2件 (8%)
```

**結論**: 日付ズレは「翌日報告」ではなく、ランダムな混在

---

### 2. 差枚エラー率分析

#### Summary の「対象差枚」 vs Detail の「合計差枚」

**問題**: 大幅な乖離

```
平均エラー: 196.1%
最小エラー: 50%
最大エラー: 442%
```

**具体例**:
```
2025-08-18: Summary報告=123,300 → Detail実績=542,400 → Error +340%
2026-01-06: Summary報告=118,600 → Detail実績=643,000 → Error +442%
```

**結論**: 計算方法が全く異なる。Summary データは単なるメモレベルの信頼性

---

### 3. 機種一致性分析（重要発見）

#### 日付修正後、機種マッチング

**Analysis**: 各日のモグ玄報告機種 vs DB全体機種

```
マッチ成功: 30/63日 (48%)
マッチ失敗: 33/63日 (52%)

マッチした場合の重複率:
  Min:    1.4%
  Max:    6.2%
  Mean:   2.1%
  Median: 1.5%

※ モグ玄報告機種 (2-20個) vs DB全体機種 (715個)
```

**結論**: 「高設定台を選別している」可能性を示唆（全体の2%程度しか報告していない）

---

### 4. 高差枚機種との関連分析（致命的発見）

#### モグ玄報告機種 vs DB「Top10高差枚機種」

**Analysis**: 各日、モグ玄が報告した機種が、その日の高差枚機種トップ10に含まれているか

```
サンプル日数: 10日

重複率統計:
  Min:    0%
  Max:   50%
  Mean:   5%
  Median: 0%
```

**具体例**:
```
2025-08-18:
  モグ玄報告: レヴュースタァライト, 麻雀物語, カバネリ（3機種）
  DB Top10: ダーリンイナザウーザー, スーパーブラックジャック他
  重複: 0件 (0%)

2025-08-31:
  モグ玄報告: ハッピーVⅢ, レヴュースタァライト他（7機種）
  DB Top10: ToLOVEダークネス, 魔法少女他
  重複: 0件 (0%)
```

**結論**: **モグ玄報告機種は、その日の「高差枚機種」とは無関係。つまり「高設定台」を報告していない可能性が極めて高い。**

## Pocoデータの検証結果

### 日付・差枚の一致性

```
DB記録との一致: 100%（全188件マッチ）
差枚完全一致: 100.0%（全日付でDB全体差枚と完全一致）
```

### 結論

ぽこは「ホール全体の日次成績」を報告している。「高設定台のみ」ではなく「全台成績」。

ただし、「仕掛け内容」欄に記載の戦略情報（「全→マギレコ, モンハン」など）は、店側の設定投入位置を推測したものと考えられる。

---

## 最終評価

### モグ玄データ: ❌ 信頼度低

**根拠**:
1. Summary と Detail の日付ズレ（50% shift）
2. 差枚エラー率 196%（計算方法が異なる）
3. 機種全体マッチ率 2.1%（高設定台選別の可能性）
4. **高差枚機種マッチ率 5%（致命的）← 「高設定台」を報告していない**

**推奨**:
- ❌ ML 学習には使用しない
- ❌ 高設定台の指標としては使用しない
- ⚠️ 「定性的な参考資料」程度の扱いに留める
- ❓ 報告方法を報告者に確認してから再判定

---

### ぽこデータ: ✅ 信頼度高

**根拠**:
1. 日付 100% マッチ（全188件）
2. 差枚 100% マッチ（DB全体値と完全一致）
3. データの一貫性が極めて高い

**推奨**:
- ✅ ホール成績の外部検証データとして活用可能
- ⚠️ 「仕掛け内容」の戦略検証は別途実施
- ✅ ML 学習用の補助データとして活用可能

---

## 推奨アクション

### 優先度「高」

1. **モグ玄報告者への聞き取り**
   - 「対象差枚」の計算ロジックは何か？
   - 「対象機種」は「高設定台」なのか、別の基準なのか？

   - 「全→マギレコ」は実際に蒲田7のマギレコが高設定だったのか？

### 優先度「中」

3. **蒲田1 データの同等分析**
4. **ML活用プラン再検討**
   - モグ玄: 使用見直し
   - ぽこ: 積極活用検討

---

## 結論

**モグ玄は「高設定台報告」ではなく、別の目的・基準で報告されている可能性が高い。追加確認まで信頼度は低いと判定。**

**ぽこは日付・差枚ともに完全一致。ホール成績の信頼度は高い。ただし「仕掛け内容」の正確性は追加検証が必須。**
