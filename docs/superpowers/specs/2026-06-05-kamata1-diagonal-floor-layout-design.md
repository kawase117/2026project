# 蒲田1 2F 斜めフロア配置設計

## 目的

蒲田1のフロアマップを、台番号単位のヒートマップとして元画像に近い配置で表示する。
青枠および1000円160枚コーナーの `2341-2398` は対象外とする。

## 座標方式

細分化した整数格子を採用する。斜めの島は、隣接する台ごとに
`display_x` と `display_y` を1ずつずらした階段状配置で表現する。

- `X`, `Y`: 元データ上の論理座標
- `display_x`, `display_y`: ヒートマップ描画専用座標
- 横島: `display_x` のみ1ずつ増減
- 縦島: `display_y` のみ1ずつ増減
- 斜め島: `display_x` と `display_y` を同時に1ずつ増減

半セル座標や浮動小数点座標は使用しない。

## CSV

`Heatmap/2F_floor_coordinates.csv` は次の列を持つ。

```text
hall_name,machine_number,X,Y,display_x,display_y,section,section_min,section_max,rank_from_min,rank_from_max
```

`section` は同じ島または連続した列に属する台番号の最小値と最大値を
`小-大` 形式で保持する。順位列は台番号の昇順と降順の両方を保持する。

## 描画

共通描画処理は `display_x` が存在する場合に表示用X座標として使用し、
存在しない既存CSVでは従来どおり `X` を使用する。Y座標も同様に
`display_y` を優先する。

これにより蒲田7とみとや大森町の既存表示を維持しつつ、蒲田1だけ
階段状の斜め配置を描画できる。

## 検証

- 台番号の重複がない
- 表示座標の重複がない
- `2341-2398` が含まれない
- セクション内の順位が1から台数まで連続する
- 代表的な斜め島で隣接台の座標差が `(1, 1)` または `(1, -1)` になる
- Streamlit画面で横島、縦島、斜め島、通路が判別できる
