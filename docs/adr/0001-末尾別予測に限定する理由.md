# 末尾別予測に限定する理由

## 決定

機械学習による高設定台予測は、**末尾別（台番号の1の位、11種類）の相対順位（Rank1/TOP2/TOP3）予測に限定する**。機種別（40種類）と台番号別（600台）は当面対象外とする。

## 背景

粒度（分析の粗さ）によって、店の設定投入パターンの可観測性と予測可能性が大きく異なる。どの粒度から始めるかは、モデル開発の基礎となり、変更コストが高い決定である。

## 検討した選択肢

### 1. **末尾別（11種類）** — 採択
- 粒度：最も粗い
- 蒲田七での実績：LTR モデルで hit_at_2 = 44.3% vs random 34.2% （**lift +10.1%**）
- ツートップ効果への耐性：相対的な傾向が残りやすい
- 実装の安定性：高い

### 2. **機種別（40種類）** — 検討後、却下
- 粒度：中程度
- 課題：「人気台 vs 不人気台」という根本属性が存在
- ML での役割：機種名が大きな要素（設定投入より機種特性が強い）
- 入れ替え：月2-3回、過去パターンは無効化されない（ただし新規機種時に学習が必要）
- 検証状況：蒲田七では未実装（他ホールも未検証）

### 3. **台番号別（600台）** — 検討後、却下
- 粒度：最も細い
- 課題：データスパース、設定投入パターンのランダム化が強い
- サンプル数：1台あたり数日～数十日のデータのみ
- 予測可能性：低い
- 検証状況：未実装

## 採択理由

### 1. **蒲田七での実績が明確**
- 相対順位（TOP2/TOP3）予測で有意なリフトを達成
- Rank1（細粒度）では失敗しているが、TOP2/TOP3 では成功
  - is_rank_1: hit_at_1 = 3.3% vs random 8.6% （**lift -5.4%**）
  - is_top_2: hit_at_2 = 44.3% vs random 34.2% （**lift +10.1%**）
  - is_top_3: hit_at_1 = 34.4% vs random 26.8% （**lift +7.6%**）

### 2. **粒度と予測可能性の関係**
- 末尾別（11種類）：相対順位でランダム化の影響を吸収できる粒度
- 機種別（40種類）：人気度という根本属性が存在し、設定投入ロジックが複雑
- 台番号別（600台）：データスパース、ランダム化が完全に支配的

### 3. **ツートップ効果への対応**
- 店は1位と2位に設定を投入することが多い（実感ベース）
- Rank1（1位確定）より TOP2/TOP3（順位帯の確定）の方が安定的に予測可能
- 運要素による順位入れ替わりは末尾別粒度では相対的な傾向として吸収される

### 4. **他粒度への拡張の道を残す**
- 末尾別の成功パターンが確立した後、機種別・台別への拡張が可能
- 各粒度は独立した予測対象として段階的に実装可能

## 結果・影響

### 変更コスト：**高い**
- ML パイプライン全体（特徴量エンジニアリング、モデル構造、評価メトリクス）の基礎
- 別粒度への切り替えには、データセット再構築、モデル再学習が必要
- ダッシュボード（page_05, page_09）が末尾別に最適化

### 長期的含意
- **ホール固有性**：蒲田七での検証結果が他ホールでも成立するかは未検証
- **ランダム化レベル**：「どの程度のランダム化が全ホール共通か」は未検証
- 今後、他ホール・他粒度での検証を進める際の参考基準となる

## 却下された選択肢の復活条件

**機種別への切り替え**が検討される条件：
- 機種ごとの「人気度スコア」を明示的にモデルに組み込む設計が確立した場合
- 機種入れ替えを特徴量として組み込む方法が確立した場合

**台番号別への切り替え**が検討される条件：
- ランダム化の「程度」を定量化できる指標が発見された場合
- 超長期データ（数年単位）が蓄積され、スパース性が改善した場合
